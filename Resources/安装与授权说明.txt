KeyCount — 安装与授权

一、先安装，再运行
1. 退出旧版 KeyCount，避免同时运行多个副本。
2. 将本窗口中的 KeyCount.app 拖入 Applications（应用程序）。
3. 推出 DMG，从 Finder 的“应用程序”里打开 KeyCount。
4. 若提示无法验证开发者或应用未公证，打开“系统设置 → 隐私与安全性”，
   点击“仍要打开”，再在弹窗中点击“打开”，按提示完成认证。
5. 不要从 DMG 内直接启动或给 DMG 内的副本授权。

二、开启需要的权限
1. 点击菜单栏 KeyCount 图标 → 开启辅助功能。
2. 在“系统设置 → 隐私与安全性 → 辅助功能”中允许 KeyCount。
3. 如需按键次数、小时分布，再在应用偏好设置中开启“输入监控”。
4. 输入监控授予后，如果系统要求退出并重新打开，请按系统提示操作。

三、已开启但应用仍提示未授权
1. 先退出 KeyCount。
2. 在上述权限页面中移除旧的 KeyCount 条目。
3. 重新添加“应用程序”内的 KeyCount.app 并开启权限。
4. 重新打开“应用程序”内的 KeyCount，等待几秒。
5. 仍异常时，在应用偏好设置中“复制授权诊断信息”，与弹窗截图一起反馈。
   诊断仅含系统版本、应用运行路径、签名及授权状态；分享前可隐去路径里的用户名。

四、签名说明
GitHub Release 中的 local 包使用 ad-hoc 签名，未经过 Apple 公证。
这些包可以按上述步骤安装和使用，无需 Apple 开发者账号。
更换测试构建后可能需要重新添加权限条目，不能承诺跨版本保留授权。
Developer ID 签名和公证是可选的后续分发方案。

不需要关闭 SIP 或 Gatekeeper，不要导入别人提供的私钥，也不需要清空整机权限数据库。
